## PDESC001 wire format

Use deterministic binary encoding to avoid different JSON number, duplicate-key or serialization interpretations across JS/C. Maximum descriptor length is65536 bytes, inclusive of the16-byte header. Header: eight ASCII bytes PDESC001; total length u32 big-endian; field count u16 big-endian exactly24; reserved u16 exactly0. All24 fields occur once, in ascending tag order1..24. Each field is tag u16, payload length u32, then exactly that many payload bytes. Unknown tags, missing/duplicate/reordered fields, unknown magic, flags, nonminimal/incorrect lengths, trailing bytes, truncation or arithmetic overflow reject. Compute bounds before allocation, slicing or addition; do not depend on native struct padding or endian order.

Types: H is exactly32 raw SHA-256 bytes, not hexadecimal text. U is unsigned64 big-endian, range1..2^64-1; JS uses BigInt, never Number coercion. T is1..1024 bytes of strict UTF-8 without NUL, ASCII controls or invalid/overlong/surrogate sequences; no normalization or case folding. Identity fields additionally use ASCII [A-Za-z0-9._:/-], at most256 bytes. A vector is u16 count followed by count entries of u32 byte length plus exact payload, with no padding/trailing bytes. Nested vectors are forbidden except the explicit record definitions below; total depth is bounded by3. An optional empty vector is permitted only where explicitly stated. A decoder must reject a value outside these limits before exposing a decoded record. The constructor has the same limits, and decode/encode must reproduce identical bytes. H values are equality bindings, not standalone proof of authority.
