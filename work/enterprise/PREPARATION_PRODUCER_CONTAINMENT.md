## Closing the domain and authenticating proof

Persist ADMISSION_CLOSED and revoke all future GO/admit operations for the exact generation. That terminal admission decision survives controller restart. A frozen cgroup is not empty and is not sufficient. After optional bounded graceful stop, use cgroup.kill on the held, authenticated domain descriptor and wait for cgroup.events populated=0 for the complete subtree. Refuse timeout, permission error, threaded/invalid cgroup, replaced mount/inode, changed boot, migration permissions, orphaned supervisor or missing admission history. Do not remove/reuse the cgroup until its proof and outputs are durable. An empty newly created cgroup cannot stand in for a deleted original.

Once empty with admission irreversibly closed, drain and close supervisor output handles, flush filesystem writes, inventory output by streaming hash/length (do not retain the entire output corpus in memory), fsync and read back. Seal a supervisor-owned immutable copy inaccessible to workload UIDs, compare file set/bytes again, and publish PRODUCTION_DOMAIN_CLOSED schema1. It binds PREPARED/ADMITTED/ADMISSION_CLOSED, exact domain generation, native empty observation, policy, workload/source inputs, supervisor identity, exit/stop diagnostics and sealed inventory. Failure to persist proof keeps the owner/fence/intent; it never fabricates FAILED or clean quiescence. Unknown original exit remains unknown even if present domain emptiness is proven.

The proof is authenticated from supervisor-owned records and the real native invocation, not accepted merely because JSON has the expected fields or a hash. Bind its raw bytes and authenticated provenance into start/runtime evidence and failure/recovery manifests, then transitively through terminal closure, request, candidate, both review Phases and acceptance. Capture, gate, candidate, review and import use one private validator. Readonly consumers verify immutable evidence; they neither call the supervisor to perform recovery nor grant new execution authority. For an interrupted contained fixture, feed this proof into the existing recovery state machine; all CAS/fsync/readback phases, original-fence-last release, no fallback and unknown historical outcome requirements remain.

The native launch protocol is not idempotent by numeric PID. The operation key is run/attempt/start-hash/domain-generation. Same authenticated retry inspects the protected state and returns the same durable result; a new launch requires a new attempt. Crash before ADMITTED, after GO, while closing, after empty observation, during sealing or after terminal commit retains an intent/fence until an authenticated continuation proves that exact stage. Supervisor restart with missing generation state must reject. Response loss after complete persistence is a readonly requery, never a second GO or second abort.

## Primary interface references and limits

Linux cgroup v2 documents inherited membership, subtree populated status and cgroup.kill's handling of forks/migrations: https://docs.kernel.org/admin-guide/cgroup-v2.html . This supports the kernel primitive, not the whole proposed isolation or current environment availability. no_new_privs is inherited across fork/exec but does not by itself prevent all privilege changes or descriptor receipt: https://docs.kernel.org/userspace-api/no_new_privs.html . Seccomp is a syscall-filtering component rather than a complete sandbox: https://docs.kernel.org/userspace-api/seccomp_filter.html . All policy, filesystem, IPC, supervisor and crash guarantees above are implementation/test obligations, not claims that documentation proves this application correct.
