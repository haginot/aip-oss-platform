# ENT-107 AI提案境界と機密情報保護

状態: OPEN（GitHub未登録）

親: ENT-100

依存: ENT-102

## 現状との差分

現在model/agent/parse等は未採用として明示拒否される。

## 受入条件

- [ ] モデル入力前に認可し、prompt injectionで権限を増やせない
- [ ] 根拠参照・型・tool allowlist・費用上限を検証する
- [ ] AIは提案のみ。採用/労務の重大判断と外部公表は人の承認を要求する
- [ ] モデル停止時も手動業務を継続し、新規有料依存を必須にしない

## 共通の完了条件

- 現行コードと検証定義のhash、実行コマンド、終了コード、証跡、独立レビューを添付する。
- 正常系だけでなく拒否・競合・失効・再送・失敗後の照合を検証する。
- 実環境の接続・法適合・本番保証をローカルsynthetic実演と混同しない。
- 親Issueは全子Issueが検証済みになるまでcloseしない。
